# Homework 1 — Unit Testing with Pytest
Домашнее задание по автоматизированному тестированию.
запуск из корня проекта командой: pytest hw1

================================================================================
pytest	Запустить все найденные тесты
pytest hw1	Запустить тесты только из папки hw1
pytest test_file.py	Запустить конкретный файл
pytest -v	Подробный вывод: показывает имя каждого теста
pytest -q	Краткий вывод
pytest -s	Показывает print() из тестов
pytest -k "square"	Запустить тесты, в имени которых есть square
pytest -m smoke	Запустить тесты с маркером smoke
pytest -x	Остановиться после первого упавшего теста
pytest --maxfail=2	Остановиться после двух ошибок
pytest --lf	Запустить только тесты, которые упали в прошлый раз
pytest --ff	Сначала запустить тесты, которые упали в прошлый раз
pytest --collect-only	Показать, какие тесты будут запущены, но не запускать их
pytest -h	Показать все доступные параметры
pytest --tb=short	Сократить traceback при ошибке
pytest --disable-warnings	Не показывать предупреждения
